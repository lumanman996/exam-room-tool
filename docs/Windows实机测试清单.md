# 考场编排 1.2.1 Windows 实机测试清单

此清单用于新包交付后的实际电脑测试。开发阶段的自动结果另记，不用本表提前判定实机通过。请把整个 ZIP 复制到 Windows 电脑，完整解压后双击“考场编排.exe”，保留同目录全部文件。先用虚构示例练习，截图只用虚构资料。

1.2.1 只改了“单独排座科目”的座位编排，1.2.0 的其他内容已经实机测过。每项记录“正常 / 有问题”，有问题时写下操作步骤、预期与实际结果、提示文字和 Windows 版本。

## 1.2.1 改动

1. **版本**：「使用说明 → 联系与版本」显示 1.2.1；已激活的电脑升级后仍是已激活。
2. **为单独排座科目预留位置**：设置一个大考场和一个小考场；某个年级的固定座位科目，与另一个年级的单独排座科目安排在同一时段，且两个年级不能混排。先自动编排固定座位，再编排单独排座的科目：两者都应排下，固定座位会主动让出单独排座科目需要的考场。
3. **确实排不下时的提示**：在第 2 项的基础上，增加单独排座科目的人数，直到任何考场都坐不下。自动编排固定座位时，固定座位仍会保存，并提示「单独排座的科目（科目名）在这些固定座位下可能排不下」以及处理建议；之后编排这个科目时会提示排不下。
4. **两种考号方式**：在「座位与考号」页分别选「按考场座位」和「流水号」，各做一遍第 2 项，结果都正常，考号不重复。

## 回归与完整流程

5. **完整流程及实际材料**：资料 → 日程 → 座位与考号 → 监考 → 检查确认 → 导出。打开实际 Excel、PDF 或打印页面，核对单独排座科目的考场、座位与考号。
6. **打开 1.2.0 保存的方案**：能正常打开、检查和导出，已有的座位和考号不变。
7. **检查更新**：等 1.2.1 发布到 GitHub 后，在 1.2.0 上点「检查更新」应能找到 1.2.1 并自动更新。发布前这一项先跳过。

Windows 包交给你后，开发、构建和追加测试暂停，等待实机反馈；发现问题再按影响范围安排处理。
