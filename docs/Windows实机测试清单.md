# 考场编排 1.2.0 Windows 实机测试清单

此清单用于新包交付后的实际电脑测试。开发阶段的自动结果另记，不用本表提前判定实机通过。请把整个 ZIP 复制到 Windows 电脑，完整解压后双击“考场编排.exe”，保留同目录全部文件。先用虚构示例练习，截图只用虚构资料。

每项记录“正常 / 有问题”，有问题时写下操作步骤、预期与实际结果、提示文字和 Windows 版本。1.1.0 已测过且这次没有改动的功能，只在第 9 项里快速过一遍。

## 1.2.0 新增和改动

1. **启动、版本和激活**：「使用说明 → 联系与版本」显示 1.2.0，联系方式为微信。已在 1.1.0 激活过的电脑，升级后仍是已激活；新电脑显示试用 3 天，复制机器码后用新发码器发码激活，重开后仍保留。
2. **考号方式：按考场座位**：在「座位与考号」页，自动编排座位按钮前选「按考场座位」。安排同一年级有不同选考科目的学生，编排后生成考号，核对没有重复考号，每个学生各占一个固定座位。
3. **考号方式：流水号**：改选「流水号」后重新编排座位。时间不重叠的学生可以共用座位；只考单独排座科目的学生不占固定座位，但能拿到流水号考号，单独排座的座位和材料正常。考号生成那一步显示的方式与这里一致。
4. **切换方式的提示**：先按流水号排好座位，再改回按考场座位，生成考号和检查时应提示“当前座位按流水号方式编排，请重新编排座位或改用流水号”，不会生成重复考号。
5. **打开 1.1.0 的旧方案**：如果旧方案里有不同年级共用座位的情况，检查会提示需要处理。把考号方式改为流水号后，原有考号保持不变、检查通过；或者重新编排座位。
6. **排不下时的提示**：故意减少考场或座位，自动编排日程和座位，提示应说明具体原因（例如哪个时段人数多于座位，或者建议增加考场、改用流水号），不再只有一句通用提示。
7. **撤销按钮**：顶栏只有一个撤销按钮，按钮上写明这一下撤销什么：有未保存输入时是「撤销输入」，否则是「撤销：自动安排监考」之类的操作名称。点一次，核对撤销的正是写着的那一项。
8. **出错提示**：正常操作中如果出现错误，提示应为中文说明，不出现英文或程序内部文字。导出时目标文件正被 Excel 打开，应提示先关闭文件。

## 回归与完整流程

9. **1.1.0 功能快速回归**：年级设置与批量删除、考场批量创建与修改、行列调整、恢复默认参数、科目与分钟时长、批量添加科目、学生拖动和座号拖动、检查定位与返回，各操作一次，确认没有退化。
10. **完整流程及实际材料**：两种考号方式各走一遍：资料 → 日程 → 座位与考号 → 监考 → 检查确认 → 导出。打开实际 Excel、PDF 或打印页面，核对姓名、场次、教室、物理位置、座号、考号；先打印一页核对中文和纸张方向。
11. **保存、备份与退出**：关闭重开、另存方案、恢复备份，核对方案、记录和材料一致；试系统的文件选择与另存对话框。
12. **检查更新**：等 1.2.0 发布到 GitHub 后，在 1.1.0 上点「检查更新」应能找到 1.2.0。发布前这一项先跳过。

Windows 包交给你后，开发、构建和追加测试暂停，等待实机反馈；发现问题再按影响范围安排处理。
