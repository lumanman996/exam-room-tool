# 考场编排 1.1.0 Windows 实机测试清单

此清单用于新包交付后的实际电脑测试。开发阶段的自动结果另记，不用本表提前判定实机通过。请先复制整个 ZIP 到 Windows 电脑，完整解压后双击“考场编排.exe”，保留同目录全部文件。先用虚构示例练习。

每项记录“正常 / 有问题”，有问题时写下操作步骤、预期与实际结果、提示文字和 Windows 版本。截图只用虚构资料。

1. **启动和显示**：首次打开、中文输入、窗口缩放、浅色/深色、字体增减和重置；关闭重开后设置保留。
2. **第一步设置年级**：新建考试先填七、八、九年级，也试自定义名称和手动追加。年级数量随列表更新；后续导入和混排范围使用这份清单。
3. **年级批量删除**：勾选、全选、一键删除未使用年级；已有关联的年级能看到具体关联并返回处理，避免误删。删除后试撤销。
4. **两种恢复**：同一页面连续修改后撤销上一步，再恢复到上次保存；另页已经保存的内容保持。保存后试提交撤销，关闭重开再核对。恢复后继续操作下拉、勾选和动态表单。
5. **考场批量创建**：直接填编号、数量、名称、行列、每桌人数、停用位置及可用时段；预览实际布局和容量，再确认创建。编号冲突应保留原资料和输入。
6. **考场批量修改/删除**：只修改勾选的考场和字段；其他资料保持。已有学生或监考时，核对影响提示后再操作，试撤销和重开。
7. **考场行列调整**：在基础资料找到行列控件，观察布局和容量变化。缩小已有编排的考场，核对受影响的学生、锁定座位和处理入口。
8. **恢复默认参数**：分别试编排、监考、考号、求解、考场布局、主题和报表等现有设置组的默认复位。只复位当前参数，不清空学生、考场、考试等名单；可保存、撤销。
9. **科目与分钟时长**：手写科目、下拉选择、编辑预设；预设修改不改变已有日程。试开始 08:20、结束 09:55，显示时长应为 95 分钟；未定时间时保留计划分钟。
10. **批量添加科目**：选择多个年级和科目，核对组合预览及重复提示；一次确认后保存，重开一致。试批量调整时间与删除。
11. **标签和顺序引导**：当前标签醒目，未保存有标记；上一步与保存并继续可用。失败时留在原页并保留输入；普通表格修改不会突然跳转。考试设置保存后收起，点外面也可收起，再打开保留未保存输入。
12. **学生拖动**：拖到空位或另一学生位置，先看移动/交换预览再确认。试锁定、停用位置和单科场次；也试点选/键盘替代操作及撤销。
13. **座号拖动**：切换到座号模式，交换标签后学生物理位置和锁定位置保持；各场次一致。核对需要复核的自动考号、人工考号，以及恢复默认座号。取消或切换考场后，旧预览不能再弹出。
14. **检查处理与返回**：点击具体问题能定位对象或字段，修改后返回重新检查；同类重复问题能合并并在支持时批量处理。硬规则问题仍需实际解决。
15. **帮助和激活**：查看分类帮助、字段解释、机器码复制和联系信息；观察试用/激活状态及重开保留。不要把许可私钥或真实许可发给测试人员。
16. **完整流程及实际材料**：资料 → 日程 → 座位与考号 → 监考 → 检查确认 → 导出。打开实际 Excel、PDF 或打印页面，核对姓名、场次、教室、物理位置、座号、考号。先打印一页核对中文和纸张方向，再试需要的 A3/A4 版式。
17. **保存、备份与退出**：关闭重开、另存方案、恢复备份；核对当前方案、记录和材料一致。试系统文件选择与另存对话框。

Windows 包交给你后，开发、构建和追加测试暂停，等待实机反馈；发现问题再按影响范围安排相关负责人。
