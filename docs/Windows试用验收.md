# 考场编排 Windows 实机试用

先把整个 ZIP 复制到 Windows 电脑并完整解压，再双击“考场编排.exe”。保留同目录的全部文件，先用虚构示例熟悉操作。

建议按下面顺序测试，每一项记下“正常 / 有问题”和实际表现：

1. **启动与显示**：首次打开、中文输入、窗口缩放、字号和主题是否正常。
2. **第一步年级设置**：新建考试，先设置本次考试的年级数量和名称，例如七、八、九年级；保存重开后仍一致。后续资料中的未知年级应提示先核对或修改基础设置。
3. **资料导入**：用少量虚构学生、教师、考场和日程测试空白模板导入，核对预检和保存结果。
4. **编排选择**：分别试“各年级分别编排”“两个年级混插”“全部年级混排”；核对显示的年级范围。保存一个自定义年级组，再从同一编排区域选中并应用。
5. **考试设置面板**：成功保存后收起；点面板外收起，重新打开后未保存输入仍在；保存失败时错误和输入保留。
6. **完整流程与备份**：日程 → 座位与考号 → 监考 → 检查确认 → 导出；试一次人工调整、保存、关闭重开和“另存方案”备份恢复，核对同一方案数据。
7. **实机导出和打印**：打开导出的 Excel、PDF 或可打印 HTML；先打印一页，核对中文、纸张方向、页数和名单，再试需要的 A3/A4 版式。

遇到问题时记录：Windows 版本、操作步骤、预期结果、实际结果及提示文字。可使用虚构数据截图复现，避免发送真实学生资料。
