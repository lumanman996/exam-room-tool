# 前端改造实现计划

用户已批准前端规划及前后端并行分工。本计划直接执行，源码验证后反馈；不在本轮反复构建桌面安装包。

目标：落实两套主题、可增减字号、流程导航、资料与座位工作区、监考与检查定位，以及可实际生效的导出排版设置。

架构：保持原生 HTML/CSS/JS 和既有 Python 核心。显示偏好独立保存；页面状态与方案分开；请求与后台任务继续通过本机服务。前端拥有 UI 文件，另一对话拥有 Python 核心与导出接口，共同文件按约定交接。

## 文件职责

- exam_room/ui/appearance.js：启动主题、系统监听、字号与密度、本机显示偏好。
- exam_room/ui/style.css：两套语义颜色、全页面组件、字体与窗口适配。
- exam_room/ui/index.html：工作区结构、总览、资料标签、座位与监考视图、设置和导出预览。
- exam_room/ui/app.js：请求、保存与任务状态；整合新页面，保留原始业务入口。
- exam_room/ui/workspace.js：总览、上下文记忆、搜索分页、座位和监考面板、检查定位。
- exam_room/ui/export.js：按后端能力提供排版设置、保存、预览和导出。
- exam_room/ui/numbering.js：预览分页、只看改变号码；保留独立撤销与版本控制。
- exam_room/ui/rooms.js、controls.js：已有布局和时间控件的交互适配。
- tests/frontend：原生 Node 测试显示偏好、搜索分页和上下文行为。
- tools/check_frontend.py：隔离虚构数据运行真实浏览器流程、截图、性能和导出检查。
