# 考号与考场设置实现计划

**目标：** 实现用户确认的自定前缀加两位考场、两位座位考号，并完善考场设置。

**架构：** 新建 numbering.py 隔离考号预览、应用、撤销及来源检查；rooms.py 负责批量考场和布局校验。server.py 提供事务接口；engine.py 接入来源检查；原生界面提供预览与专用布局编辑。

**技术栈：** Python 3.12、现有本机服务、HTML/CSS/JavaScript、pytest、Playwright。
