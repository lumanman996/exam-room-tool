# 验测台自动执行实现计划

目标：用户不用手动导入、点击或对表，由本机自动执行虚构场景、完整页面操作与导出核对，生成可复跑报告。

架构：命令入口调度独立子进程；每阶段使用新隔离目录，核心场景通过真实 HTTP 服务；浏览器操作实际前端和后端。独立断言验证参试集合、时间、位置、监考和导出。超时、失败、环境阻塞分别记录，保留首次失败证据。

技术栈：Python 3.12、pytest、urllib、Python Playwright、openpyxl、pypdf。仅增加开发依赖，不修改生产许可或用户数据，不构建桌面包。

## 文件职责

- `tools/run_testbench.py`：quick/full、阶段子进程、时限、聚合报告、退出码。
- `tools/testbench/common.py`：案例记录、本机 HTTP 服务生命周期、独立规则与 Excel 核对。
- `tools/testbench/scenarios.py`：36 份样本及保存、人工调整、并发、口令、导出集成流程。
- `tools/testbench/browser.py`：上传四类表、编排、界面编号与时间调整、恢复、Excel/PDF 下载及重开。
- `tests/test_testbench.py`：错误不能误报通过，独立断言捕获坏座位与教师冲突，报告转义与超时行为。
- `docs/验测台测试方案.md`、`testkit/README.md`、`README.md`：可运行入口和实际覆盖范围。
