# 座号方向、年级混插和时间输入

用户已要求直接实现。考号规则维持“自定义前缀 + 两位考场编号 + 两位座位号”。

1. 考场增加 direction（horizontal / vertical），旧方案默认 horizontal。与 order（straight / snake）组合提供四种编号路线，以讲台方向为参照。停用、容量、双人桌、预览及打印共用核心布局。
2. 座位页面提供各年级分别、两个年级、三个年级混排按钮，两个年级可选组合，保留高级自定义组。时间完全一致的兼容年级按座号轮流交插；锁定位置优先，人数不等时继续安排剩余学生，不同参试时间的学生保留安全分配。
3. 座位页可将编号方向和顺排/S 型应用到当前或全部考场，已有安排标记待复核。
4. 日程及可用时段使用 HH:MM 文本框，旁边提供减 5 / 加 5 分钟按钮。支持半角、全角冒号；拒绝错误时间和越日调整；逐行保存，避免输入一半就刷新。手工保存起止时间时自动计算考试时长，锁定状态保留。
5. 先运行回归测试确认缺口，再实现。验收：四种编号、双人桌和停用位、2/3 年级交插及锁定、手输/按钮/保存重开，检查导出一致性。
6. 构建新 Mac 包时使用隔离输出目录，保留用户正在运行的旧应用及本机数据。
