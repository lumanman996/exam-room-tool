# 原生验收入口实现计划

目标：沿用已批准的下一阶段交付计划，在隔离虚构目录验证真实pywebview宿主、页面保存、独立材料和重启；不重复full、不修改产品、不构建。

架构：父进程准备跨平台清单和样本，监督两个独立原生子进程（首次及重启）。子进程在主线程启动pywebview，后台通过evaluate_js触发DOM操作，真实本机HTTP负责业务。窗口隐藏且不获取焦点，不使用CUA，不打开系统对话框。报告单独列出未运行的平台、真实键鼠、系统文件选择和打印；隐藏宿主通过不等于可见桌面完整验收。

文件：tools/native_acceptance.py负责入口、隔离、环境、指纹、监督及报告；tools/testbench/native_worker.py负责真实宿主和页面操作；tests/test_native_acceptance.py防止无宿主/错误基线/非交互会话误报；docs/原生验收记录.md记录平台矩阵、入口与证据。
