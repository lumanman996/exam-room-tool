# 考场编排使用手册

适用于「考场编排」1.2.0 的界面与操作。资料、方案和编排在本机处理；本手册中的姓名、日期和学校均为虚构示例。各平台安装、启动及打印设备说明随最终交付提供。

## 1. 第一次使用

可以先点击首页的「用虚构示例试一试」，熟悉操作，再新建实际考试。推荐按以下顺序完成：

1. **新建考试**，填写名称和参试年级列表；用「添加年级」增加一行，数量自动更新，在顶部「考试设置」填写学校并点击「保存考试信息」。
2. **基础资料**：准备学生、考场、教师和考试科目，先预检再导入。
3. **考试日程**：录入已有时间，或设置可用时段后自动安排。
4. **座位与考号**：安排固定座位，核对后生成考号。
5. **监考安排**：自动编排，再补齐或调整教师。
6. **检查与确认**：处理必须修正的问题，复核当前方案。
7. **导出打印**：选择材料、调整版式，查看真实分页预览，再生成文件。

「考试总览」会提示当前缺少什么及建议的下一步。左侧工作区可以随时切换，页面底部也有「上一步」「保存并继续」。继续会先保存并核对本步必要资料；发现问题留在本步并定位。普通单条编辑保存后留在当前页。选中标签以靛蓝、边框和浮起效果标识；未保存标记同时显示文字。

## 2. 打开、复制和保存考试

首页「最近的考试」可以继续已有方案。「打开方案文件」读取另存的 JSON 文件，作为一份新的本机副本，不覆盖原考试。「复制为新考试」适合以已有资料准备另一场考试；复制后核对名称、日期、旧座位和监考，不直接把旧安排当作本次正式结果。

顶部「考试设置」保存成功后收起，点击面板外也会收起；未保存输入仍保留，重新展开可继续编辑。保存失败时保持展开并显示原因。对话框点击背景关闭时，如有未保存修改会提示保存、放弃或返回编辑，保护提示本身不会因点击背景而消失。

每次点击「保存」「确认导入」「确认生成」或成功完成编排后，方案保存到本机。顶部显示最近保存时间；**只输入文字不等于已保存**。考试名称与学校要点击「保存考试信息」，时间要点击本行保存，版式要点击「保存本方案版式」。

黄色日程行、编辑面板和「● 有未保存修改」表示还有未提交内容。离开时可选择：

- **返回编辑**：继续保留输入。
- **放弃修改**：恢复已保存内容，再继续操作。
- **保存并继续**：先保存；发现无效输入时留在原处，按提示修正。

连接或保存失败时，先保留当前输入，等待恢复后重试；看到「已保存」再关闭。需要迁移或额外备份时，在顶部「考试设置」点击「另存方案文件」，按提示查看生成的 JSON 文件，再复制到备份位置。该文件包含原始资料、设置、日程、座位、考号、监考、版式和可用调整历史；界面主题、字号和密度属于本机偏好，不随方案转移。

### 两种恢复，作用不同

- **顶栏的撤销按钮**：按钮上直接写明这一下撤销什么。有未提交输入时显示「撤销输入」，撤销最近一次输入或草稿增删；没有草稿时显示「撤销：操作名称」（例如「撤销：自动安排监考」），撤销最近一笔已保存操作。资料编辑、批量增删改、座位、监考、考号与座号排列使用同一条保存历史，最多最近 50 笔，重开考试仍可用。撤销不会回退方案版本或许可。
- **恢复上次保存**：放弃当前页、当前编辑弹窗或最近正在编辑的顶部考试设置草稿，重新显示最新保存内容；其他页面已经保存的修改保留。没有保存过的新内容恢复到本次开始编辑的状态。它不是「从备份恢复」。

弹窗里有「撤销输入」「恢复上次保存」按钮，外侧工具栏不可点击时也能使用。保存一条日程后，其他行的草稿保留，仍可撤销其输入或恢复最新保存。保存失败保留输入和预览，按提示重试；如版本已改变，须重新预览。

### 恢复本项默认

编排、监考、考号、求解时间、布局方向、考场布局、批量创建布局、外观、打印版式和科目目录分别提供自己的恢复默认入口。参数先回到当前组草稿，按原流程保存；姓名、年级、学生名单、考场名称与实际考试日程不因此清空。外观仍独立自动保存。

## 3. 主题、字号与密度

左下角展开「外观与设置」。

| 设置 | 使用方法 |
|---|---|
| 主题 | 默认「跟随系统」，也可手动选择「明亮」或「暗色」 |
| 界面字号 | A− 缩小、A＋ 放大；每次 5%，范围 90%～150% |
| 恢复字号 | 只把界面字号恢复为 100% |
| 表格密度 | 「标准」留白较多，「紧凑」在同一窗口显示更多内容 |
| 恢复外观默认设置 | 恢复跟随系统、100% 字号和标准密度 |

这些偏好在本机跨考试保存，重启后沿用，不改变学生安排。暗色界面仍显示白纸打印预览；界面字号与材料的打印字号分别设置。

## 4. 准备和导入资料

基础资料第一块是「本次考试年级」，显示已设名称和各年级学生人数；0 人的年级也会保留。点击「添加／修改年级」，逐行手写名称，用「添加年级」增加行；数量自动显示。空白草稿行可勾选后删除，或撤销添加。名称可以自定，不能为空或重复；「初一」「七年级」等常用名称按同一年级处理。学生和科目的年级只能从这份清单选择，导入未知年级会被预检拒绝，不会自动增加年级。

未设置年级时，先设置才能添加或导入学生、科目。已有学生、科目引用的年级不能直接移除；先处理相关资料，再修改清单。打开旧方案时可能显示「请核对本次考试年级」，核对后进入「添加／修改年级」保存确认，提示才会消失。清单改动后，请按检查提示复核原编排。

年级卡片和资料表格都有勾选、全选和「删除所选」。资料表格的全选只选当前筛选范围，跨分页也会显示明确数量；筛选为空时全选不可用，已选择的其他对象仍有数量提示。删除先预览、再整批确认，可撤销。年级的「关联」列出学生、科目和混排关联，并提供定位入口；先迁移或处理关联，不能隐式删除这些资料。删除全部未使用年级后，新增学生和科目会再次引导设置年级。

在「基础资料」选择「学生名单」「考场资料」「教师资料」或「考试科目」，下载对应模板。删除模板中的示例行后填写，支持 `.xlsx` 和 `.csv`；旧 `.xls` 文件先另存为 `.xlsx`。

| 资料 | 重点填写 |
|---|---|
| 学生 | 姓名、年级、班级；学号、考号按文本保存；按需要填写成绩和参试科目 |
| 考场 | 唯一编号、名称、教室位置、桌椅布局和本次容量；需要时设置可用时段及监考人数 |
| 教师 | 姓名、任教学科、任教班级、不可监考时段 |
| 科目 | 年级、科目、考试时长；已有日程可填日期和起止时间；按需要设置锁定、单独排座及监考人数 |

年级、班级和科目名称应前后一致，班级建议带年级，例如「七1」。学生参试科目留空表示参加本年级所有科目；填写时必须与本年级考试科目一致。多学科或多班级可以用顿号分隔，例如「语文、道德与法治」。

导入步骤：

1. 点击对应的「导入…」并选择文件。
2. 核对工作表、表头行及列对应；修改工作表或表头后点击「重新识别」。
3. 选择导入方式，点击「检查这批资料」。
4. 核对新增、更新、删除数量，以及具体行的问题。
5. 预检成功后点击「确认导入并保存」。改变列对应或方式后要重新预检。

| 导入方式 | 适用情况 |
|---|---|
| 追加新资料 | 补充新学生、新考场等；重复或有冲突的资料要先核对 |
| 按唯一编号更新 | 修正现有资料；学生须能用已有唯一学号或考号匹配，不能只凭姓名 |
| 替换这一类资料 | 以这批名单作为该类完整资料；预检会列出删除影响，核对后再确认 |

同名学生分别保留，程序不按学生姓名合并。教师按唯一姓名、考场按编号、科目按年级和科目辨识；不能唯一匹配时按预检提示修正。失败的导入不会提交半批资料。

还可直接「添加」「编辑」或「删除」单条资料。学生编辑中可查看原始导入列，额外成绩列会保留。顶部搜索支持姓名、班级、学号或考号等相应内容；年级和班级筛选可组合使用，列表每页最多 100 条。搜索或筛选后没有结果时，先清除条件，不要误认为资料被删除。

### 时段的填写

教师不可监考时段、考场可用时段可写为：

```
2026-11-12 08:00-12:00；2026-11-13 14:00-16:00
```

多段用分号分开。教师未填写不可用时段表示没有额外时间限制；考场可用时段留空表示一直可用。示例日期请换成本次实际考试日期。

### 科目预设与批量添加

「考试科目 → 维护科目预设」维护名称与默认分钟，可添加模板、删除模板或恢复内置目录。目录随考试保存和转移；修改模板不追溯改变已保存的实际场次，恢复内置时保留已有考试使用的自定义模板。

单条科目可从预设下拉选择，也可直接手写新名称，不必先建模板。起止时间完整时，分钟数自动计算并只读；尚未定时间时，计划分钟可编辑，供自动排程使用。

「批量添加科目」勾选正式年级与科目，或手写新科目（多个用分号分隔），可统一日期、时间或计划分钟。先「预览新增与重复」，已有／重复的年级×科目组合会列出并保留，不覆盖旧日程。修改输入会使预览失效，重新预览后才可确认。

## 5. 设置考场和桌椅

「基础资料 → 考场资料」中点击「设置行列／布局」。讲台始终在图的上方：桌行从前向后，桌列从图中左向右；每桌人数可设置 1～4 人。

考场编号和座号均为 **01～99**。行数 × 桌列数 × 每桌人数不能超过 99。每间考场编号唯一；教室位置用于通知和教师安排，应填写实际楼栋、楼层、教室。

- **横排**：从左到右逐行编号；**竖排**：从讲台向后逐列编号。
- **顺排**：每行／列同方向；**S 型**：相邻行／列折返。
- **过道**：填它前面的桌列号，例如填「3」表示第 3、4 桌列之间有过道；多条用顿号分隔。
- 点击座位可启用或停用。「停用」禁止编排；「未使用」是启用但超出本次容量的座位。
- **本次使用容量**不能超过实际启用座位数。停用后容量会收缩；「启用全部座位并使用」恢复全部物理座位。

单场编辑先查看即时物理布局，再点击「预览实际修改与影响」。预览列出实际规范化容量、受影响学生、将移除的座位、锁定与监考；需要确认时，勾选已核对影响再保存。学生名单保留，失去的位置待重新安排，不自动移到别的考场。

已有自定义座号时，改变行列须明确勾选「本笔同时恢复默认座号」，与形状调整一起预览、一次保存和一次撤销；不能先另存一笔编号重置来隐藏影响。缩小行列后，超出新布局的停用位置会清除，保存后核对相关座位和考号提示。

「批量创建考场」设置起始编号、数量、名称前后缀，可直接填写位置、桌行、桌列、每桌人数、容量、过道、停用位、方向、顺序、可用时段和监考人数，或选择已有考场模板。预览显示服务实际采用的容量等值，确认后整批保存。

列表中勾选考场后点击「批量修改所选」，只勾选本笔要改的字段，其他值保留。可同时明确重置自定义座号后改行列。先预览实际结果及关联影响，确认后一次提交；一条不合法时整批拒绝，不留下半批资料。「复制」保留布局、教室位置、可用时段及监考人数，不带入学生或监考结果；复制后核对实际教室位置。

## 6. 安排考试日程

已有日程可以直接在每行填写日期、开始和结束时间。时间支持手输 `08:30`、全角冒号，也可点击 − / ＋ 每次调整 5 分钟。起止完整时本行分钟数实时自动计算并只读；时间留空或未完整时，可填写计划分钟。点击本行「保存」后统一时间格式；保存一行时，其他黄色行的半输入会保留。

结束时间须晚于开始时间，不能跨越当天。同一年级不能同时考两科。设置了「每天可用时段」后，手工及自动日程都必须落在这些允许时段内。

自动安排前，先添加每天可用时段并保存，再点击「自动安排时间」；锁定的时间保持。日程或时段还有黄色未保存行时，先保存再编排。

展开「指定需要同时混考的科目」，添加一组，选择不同年级、时长相同的科目，点击「保存混考组」。自动日程将这一组安排在同一时间。**同时考试的科目组**与座位页的**允许年级混排**分别设置，两项都应符合学校要求。

## 7. 编排座位、混排与人工调整

在「座位与考号 → 座位编排」展开「编排设置」。

| 编排方式 | 行为 |
|---|---|
| 班级交叉 | 尽量分散同班学生，再在检查中核对相邻提示 |
| 随机打散 | 使用保存的随机种子；资料、规则、种子和锁定共同决定安排 |
| 按成绩排列 | 选择「成绩」或原始导入中的其他成绩列；成绩从高到低，缺成绩者排在最后 |
| 按已有考号升序 | 不修改号码；纯数字按数值升序，保留原文本与前导零，缺考号者在最后 |

「年级混排」可选分别编排、两个年级混排、全部年级混排或自定义年级组。选项使用本次考试设置的年级，即使某个年级尚未导入学生也会显示；摘要列出混排组和独立年级。选择两个年级时，其余年级独立编排。自定义时点击「添加混排组」，每组勾选至少两个年级，同一年级不能出现在多个组；未勾选的年级独立编排。例如只勾选七年级、八年级，九年级保持独立。

点击「保存编排设置」保存当前规则。要重复使用自定义组合，点击「保存具名方案」，填写名称后保存；同名保存会更新原方案。在「本次考试保存的混排方案」选择后点击「应用并保存」，立即成为活动规则。具名方案随当前考试保存，重新打开仍可选择。实际考场分配以编排和检查结果为准。

兼容年级按座号轮流交插，锁定位置优先；人数不等或学生参试时段不同，可能出现不完整交插，按具体提示核对。混考起止时间不一致时不能同时使用同一考场，程序不会自动放宽规则。

在编号方向设置中选择横排／竖排、顺排／S 型及「全部考场」或「当前预览考场」，点击「应用编号设置」保存。示意图说明递增路线；已有安排改变编号规则后须重新核对。

### 先选考号方式

「开始编排座位」左边的「考号方式」决定固定座位怎么排，请在编排座位之前选好：

| 考号方式 | 固定座位 | 考号 | 适合 |
|---|---|---|---|
| 按考场座位（默认） | 每名学生独占一个固定座位，谁都不共用；只考单独排座科目的学生也占一个 | 前缀＋两位考场编号＋两位座位号，保证不重复 | 希望从考号看出考场和座位 |
| 流水号 | 考试时间不重叠的学生可以共用一个座位；只考单独排座科目的学生不占固定座位 | 前缀＋流水号 | 座位紧张、选考科目多 |

「考号生成」里的考号格式和这里是同一个设置，改哪一处都会立即保存，两处始终一致。按考场座位排不下时，提示会建议增加考场或改用流水号。已经按流水号方式排好座位后又改成按考场座位，检查和考号预览会提示"当前座位按流水号方式编排"，请重新编排座位或改回流水号。

核对设置后点击「开始编排座位」。任务期间可浏览其他页面，相关修改暂时禁用；要停止时点击「取消」，等待结果提示后再修改。出现人员不足、不可行或超时，先按提示检查容量、时段、混排和锁定；超时不等于已证明无解。

### 固定座位和科目单独安排

「查看范围」选择整次考试固定座位或某科。普通科目使用固定座位；需要单独排座的科目可以建立本场独立安排。在普通科目范围手工换座，会建立本场独立方案，按页面提示核对影响。

流水号方式下，固定总览可能显示不同时段复用同一位置的学生。「日期／时段」选择具体场次后，只看该时段人员；不要把跨时段复用误认为同时占座。正式检查仍会拦截同时占座。

### 人工调整与锁定

点击座位图中的学生，或切换「学生明细」点击「调整」，在右侧选目标考场、座号。目标有人且需要换座时勾选交换；勾选锁定后，后续自动编排优先保留。程序会检查停用位置、同时占座、时间和混排兼容，按提示修正后保存。

点击调整面板保存后先显示服务预览，核对移动／交换与锁定，再「确认调整并保存」。顶栏的撤销按钮（显示「撤销：操作名称」）撤销最近一笔操作；若之后保存了别的资料，会先撤销那笔资料，不跨过它使用旧座位快照。

### 两种拖动分开使用

- **拖动学生**：选择明确的日期／时段后，拖学生到启用且容量内的空位，或拖到另一名学生的位置预览交换。锁定的学生先通过点选调整处理；停用位、模糊复用时段和多人目标不会盲改。
- **拖动座号**：拖动两个启用位置的座号，或用「原座号／目标座号」点选预览交换。改变编号后，学生与锁定仍在原物理位置；同一考场的固定和单科映射、座位图及材料使用同一编号。点击「恢复默认座号排列」也先预览，保持物理位置。

两种模式互不混用。也可点选学生再点目标位置，或 Tab 到目标后按 Enter；浏览模式保留右侧输入调整入口。拖动只发起预览，核对后再确认保存；失败不改方案。等待预览时可按 Esc 或「取消本次预览」，切换模式、考场、范围后旧响应不再弹出旧确认。

调整后生成考号可能待复核；到「考号生成」先预览再明确生成，人工号不会自动覆盖。

## 8. 生成、核对和撤销考号

范围仍可选择已设置但暂无学生的年级；预览会说明当前没有学生，确认生成按钮不会启用。请先补齐名单，或换一个有学生的范围。

先完成固定座位，再点击「生成考号」，或进入「座位与考号 → 考号生成」。考号格式跟随座位页的「考号方式」：按考场座位时是 **前缀＋两位考场编号＋两位座位号**，例如 `26＋03＋08 → 260308`；流水号时是前缀＋流水号，可设置位数和起始号。前缀长度可自定，通常 2～4 位；考号始终按文本保存，前导零保留。

1. 填统一前缀；需要区分年级时展开「分年级设置前缀」。年级前缀留空使用上方统一前缀。
2. 选全部年级或指定年级。默认只补缺失号码；要替换旧号码时勾选「重新生成已有考号」。
3. 点击「预览新旧考号」，可分页核对，也可只看变化的学生。
4. 确认无误后点击「确认生成并保存」。

按考场座位方式下每人独占固定座位，考号不会因共用座位而重复；如果座位是按流水号方式排的，预览会提示重新编排座位或改用流水号，不会生成重复考号。分年级前缀可用来区分年级；程序不会自行添加年级码。未排座位、停用位置、超过两位的编号或重复考号会阻止整批生成。流水号方式下只考单独排座科目的学生没有固定座位，他们的材料显示单独排座的考场和座号。

固定座位或考场编号改变后，顶部会提示程序生成的考号与位置不一致。先核对、再按需要重新生成；个别科目单独换座仍保留同一考号，该科材料显示实际位置。

顶栏的撤销按钮还原最近一笔已提交操作：最近是生成考号时恢复该笔；最近是别的资料修改时先还原那笔。不能用旧号码快照覆盖后来已保存的不同资料。旧方案仍可选择「前缀＋流水号」，并设置流水号位数和起始值。

## 9. 安排监考

在「监考安排」展开规则，默认每场 2 人，考场或科目的专门设置优先。任教学科回避、任教班级回避分别设置并保存，再点击「自动安排监考」。锁定教师保留；程序检查同时两场、不可用时段及回避条件。

「按场次查看」显示考场、时间、教师位置；可按日期、搜索或「只看待安排」筛选。「按教师查看」汇总场次、分钟和具体安排，便于核对工作量。

点击待安排位置或已有教师按钮，右侧显示真实候选，按工作量从少到多排列。不可安排的教师不能选取，可展开原因查看时间冲突、学科或班级回避等。选择教师、按需要锁定，再点击「保存监考安排」；选择「留空待安排」可清空这一位置。

人员不足时保留已经可用的安排，待补位置和原因会显示。先核对教师资料及不可用时段，再补齐；不要为消除提示随意关闭学校规定的回避规则。日程合并或监考人数减少造成旧锁定冲突时，到「检查与确认」点击「去处理」，明确调整或解除失效锁定。

## 10. 检查与确认

检查按资料、日程、座位、考号和监考分组。同类根因合并显示影响数量，展开「查看对象与处理入口」查看每个对象；「去处理」定位具体资料与字段，考号问题进入新旧考号预览。

可以统一修改的问题有「批量处理」入口，只作用于列出的对象，先按相应预览和检查再提交。需要各自唯一值或存在规则冲突的问题保留逐项处理，不提供批量忽略。处理后点击「返回检查并重新核对」，用最新已保存内容重新计算，并保留原来的检查位置与展开上下文。

- **必须处理**：如缺少必填资料、重复考号、同时间占座、教师重叠、不可用时段等。相关正式材料导出会被阻止。
- **核对提示**：如同名、缺成绩、同班相邻、工作量差距等。按学校实际安排核对，可以保留合理情况。
- **待复核**：资料或规则改变后，已有结果需要重新确认，不会自动成为本次正式有效方案。

必要时重新编排或人工调整，再点击「复核并确认当前方案」。材料各自需要的检查不同：仅导出日程时，不会因为尚未安排监考而阻止；所选材料的实际要求以导出页提示为准。

## 11. 调整总表和导出打印

「导出打印」展开材料分组，勾选需要的材料。「全部选择」会选中全部 16 类；不需要的材料可取消。

| 分组 | 材料 |
|---|---|
| 教务汇总 | 按考场学生总表、学生科目明细、考试日程、学生编排总表、考场使用表、监考总表、监考工作量 |
| 学生通知 | 分班通知单、学生个人考试安排、准考证 |
| 考场布置 | 考场名单、座次表、门贴、桌贴、考场签到表 |
| 监考教师 | 教师个人安排 |

**按考场学生总表**适合汇总每个考场的学生、考号和位置；**学生科目明细**按每科实际参试和有效座位核对。科目独立换座时，不要只依靠固定座位材料判断该科位置。

### 总表版式

在「调整版式」的「材料」中选要调整的材料；每种材料可以有自己的设置。

| 选项 | 范围或说明 |
|---|---|
| 纸张、方向 | A4 / A3，横向 / 纵向；A3 需打印设备支持 |
| 每行考场数／材料块数 | 1～3 个；长考号或较多字段可减少分栏 |
| 打印字号 | 9～18 pt，独立于界面字号 |
| 行距 | 1.2～2 |
| 打印配色 | 黑白省墨或靛蓝彩色，纸面始终为白底 |
| 考场分页 | 连续分块，或每个考场另起页 |
| 页边距 | 上、右、下、左分别设置，5～40 mm |
| 字段和列宽 | 勾选需要的字段，用 ↑ / ↓ 调整顺序；列宽单位为毫米，留空自动分配 |

学生材料须保留座号、考号、姓名，避免错人；准考证和桌贴的身份信息还会显示在独立材料块的标题中。座次图按实际桌椅位置绘制，不按普通字段表重新拼装。

「编排范围」可选固定编排总览或科目有效座位，并筛选科目、考场及年级。范围选择用于当前生成，请核对结果上的适用场次；已保存的每种材料版式在重开方案后沿用。点击「保存本方案版式」保存纸张、字段等设置；「恢复本材料默认」只重置当前材料，需保存后才长期沿用。版式不会移动学生或改变监考。

建议首次先用 A4 横向、较少分栏和清楚字号核对；需要同页并排更多考场时，可尝试 A3 横向。若提示列宽不足，先减少字段或分栏、加宽考号列或调整方向，不用遮挡或截断考号来挤进纸面。

### 预览、文件和打印

1. 点击「更新打印预览」，用「上一页」「下一页」核对真实纸页，检查姓名、完整考号、场次、位置和续页。
2. 材料、范围或版式改变后重新预览，避免使用旧预览。
3. 点击「导出 Excel」或「导出 PDF」，等待后台生成；需要停止时点击「取消生成」并等待终态。
4. 生成后按显示的文件路径，点击「打开文件」或「打开所在文件夹」。桌面版在本机输出目录生成文件，浏览器版按浏览器下载方式保存；「另存方案文件」也先生成本机文件，不保证每个平台弹出另存对话框。

Excel 适合进一步核对、编辑或用表格软件打印；PDF 适合保持纸面分页。PDF 依赖本机可用的 Chrome／Edge 打印能力；找不到或生成失败时，按提示使用可打印 HTML，不把 HTML 当成已生成的 PDF。

打印时在系统或 PDF／表格查看软件中选与材料一致的纸张、方向，再核对缩放及页数。实际打印设备和各平台系统打印尚须按最终交付说明确认，PDF 生成成功不代表打印机已验证。

相关硬性问题未解决时，只能勾选「导出带标识的草稿」生成草稿；许可到期后草稿、预览及正式导出均须先激活。草稿不能当作正式考务材料。导出开始后再改方案，不会写入正在生成的旧材料；若显示「文件基于开始导出时的方案」，核对后重新生成最新文件。公开材料不包含用于排序的成绩。

## 12. 备份、删除与恢复

经常在关键节点「另存方案文件」，例如完成导入、完成座位、最终复核后。保留生成的 JSON 文件；迁移电脑时用首页「打开方案文件」读取副本，原考试仍保留。

首页删除考试会移入「回收站 · 可以恢复」，展开后点击「恢复」。需要恢复损坏文件时，先点击首页「刷新」，若程序找到可用备份，点击该考试名称，核对备份名称、时间，再点击「恢复这份备份」。程序保留损坏原件；没有可用备份时按提示保留文件并联系软件提供者。

人工调整撤销、考号生成撤销和整个方案恢复是不同操作，不互相替代。不要通过手工修改方案内部关联来消除错误。

## 13. 激活和更新

免费试用 3 天。到期后仍可编排、查看和保存；导出、预览及打印材料需要激活。在「外观与设置 → 激活与机器码」查看许可状态和分步说明，复制本机机器码与联系方式，向软件提供者获取本机激活码后粘贴。错误码提示原因并保留输入，成功后显示已激活；正式包许可模块异常时明确显示导出已锁定，查看和保存仍按提示使用。许可属于「考场编排」，与「匀班」「分寸」分别管理。

「检查更新」查看当前是否有可安装版本。更新前先保存未提交内容并另存方案备份，再按发布方提供的说明操作。各平台最终安装、签名及真实升级流程随正式交付确认，不以看到更新入口当作升级已完成。

「使用说明」按上手、资料模板、名词、恢复与批量、两种拖动、常见问题、联系与版本分类。可复制联系方式和本机数据目录路径，打开导出目录，并进入原有检查更新。带「？」的解释可点击、用键盘打开并关闭。

## 14. 键盘操作与常见问题

| 操作 | 快捷方式 |
|---|---|
| 当前列表搜索 | Mac ⌘F / Windows Ctrl+F；适用于资料、学生座位明细和监考 |
| 保存当前草稿 | Mac ⌘S / Windows Ctrl+S；无效输入仍需修正 |
| 编辑表单保存 | 输入框按 Enter；中文输入法合成期间不触发保存 |
| 取消等待中的拖动预览 | Esc；已返回的弹窗按其取消／未保存保护处理 |
| 关闭调整面板 | Esc；有未保存内容时先选择如何处理 |
| 移动焦点 | Tab / Shift+Tab；标签页也可用左右箭头、Home / End |

**找不到学生：**清除搜索、年级、班级及「只看未安排」等条件，检查当前页和当前资料标签。

**座位图同一位置出现多人：**固定总览可能包含跨时段复用，先选择实际日期／时段；如果统一检查指出同时间冲突，须处理。

**自动编排提示无解或教师不足：**检查本场容量、参试时段、混排、不可用时段、回避和锁定。增加时间只适合超时等情况，不会自动增加座位或教师。

**预检、预览后提示方案已改变：**重新读取当前方案、重新预检或预览，再确认；不要反复提交旧结果。

**考号前导零丢失：**导入前把原表的学号和考号列设为文本，并核对预检。程序保留文本号码，无法恢复源文件已经丢失的零。

**材料显示不完整或排版太拥挤：**核对范围，减少分栏或字段，加宽考号列；重新预览全部页，再生成文件。

**保存或生成失败：**保留输入，按错误提示重试；文件被其他程序占用时先关闭该文件。始终以保存及生成成功的提示为准。
