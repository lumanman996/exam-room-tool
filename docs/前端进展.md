## 已实现

- 外观：米白靛蓝明亮主题、灰蓝靛蓝暗色主题，默认跟随系统；90%～150% 字号减／增／恢复，5% 步进；标准／紧凑密度。应用偏好独立存于本机，通过启动 JSON 提前应用，换端口、重启后保留，不修改考试版本。界面字号与打印字号分开。
- 流程：总览及下一步、资料／日程／座位与考号／监考／检查／导出工作区。考试信息显式保存；保存成功才显示已保存。
- 资料：标签、搜索、年级／班级筛选、100 条分页、每个方案的筛选与页码记忆、原始导入列查看。导入追加／稳定编号更新／替换，先预检影响、再按版本提交；不以姓名合并同名学生。
- 日程：手输与每次 5 分钟增减，逐行保存保留其他半输入；无效草稿拒绝后保留。提供明确同时混考的科目组入口。
- 座位：考场列表、单考场图／学生明细、固定座位和科目范围、日期／时段查看、四种路线示意、混排与考场布局设置、右侧人工换座／锁定与影响提示。
- 考号：统一／分年级前缀、预览分页、只看变化、确认生成、撤销与版本保护；保留前导零。
- 监考：按场次／按教师、工作量、筛选和待安排位置、真实候选教师与不可安排原因、人工调整／锁定及旧锁定处理。
- 检查：按阶段分组，问题定位资料、座位、监考等具体入口；正式导出按所选材料需要的检查阶段放行。
- 导出：16 类材料分组选择、实际白纸分页预览；各材料可调 A4/A3、横竖向、1～3 栏、打印字号、行高、四边页边距、黑白／彩色、字段顺序／列宽、考场分页及范围。版式随方案保存，不使编排失效；异步导出、取消、版本快照及旧结果提示已接入。
- 编辑保护：保存／放弃／返回编辑；连接失败不关闭编辑器、不丢输入；焦点及滚动恢复，避免重复提交。编排时可查看其他页面，相关修改暂时禁用，结束后保留所查看页面。键盘搜索／保存、回车保存和 Esc 保护已实现。

依赖的新后端接口均已实际接入：静态资源、导入预检、恢复、分阶段检查、候选监考、锁定处理、分年级前缀、报告默认版式／保存、异步导出及独立外观偏好；当前没有未接入接口阻塞。
