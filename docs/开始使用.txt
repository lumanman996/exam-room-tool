考场编排 · 开始使用

一、打开程序

Mac：解压后，把“考场编排.app”拖到“应用程序”文件夹，再双击打开。
Windows：先完整解压程序文件夹，再双击“考场编排.exe”。不要只取出一个 exe，也不要直接在压缩包内运行。

各程序包用于文件名注明的平台；Mac 包面向 Apple 芯片，Windows 包面向 64 位 Windows。实际已验证的系统范围以随包验收说明为准。

二、第一次试用

首页点击“用虚构示例试一试”，或导入随包标明“虚构示例”的方案。示例只用于练习，不能用于真实考试。
新建自己的考试时，第一步先设置本次考试的年级数量和各年级名称；后续学生、科目和混排都使用这份年级清单。资料导入不会自动增加年级。
按左侧顺序完成：基础资料 → 考试日程 → 座位与考号 → 监考安排 → 检查与确认 → 导出打印。
可先熟悉编排和人工调整，再使用模板填写自己的资料。

本次改进的操作入口：基础资料可手动添加年级、勾选删除年级与考场；考场可批量创建和修改，并直接填写行列数。科目可手写或从预设选择，也可按多个年级批量添加；起止时间完整后按差值显示分钟数。
顶部提供“撤销上一步”和“恢复上次保存”。前者先撤销最近输入，没有草稿时撤销已保存操作；后者放弃当前页面或弹窗的未保存输入，保留其他已经保存的修改。各参数组的“恢复默认”只复位本组参数。
底部“保存并继续”按步骤引导，“上一步”可返回；未完成或保存失败时先处理提示。座位图分别提供调整学生和调整座号模式，每次先核对预览再确认；调整座号时学生物理位置保持，生成的考号按提示复核。

三、准备资料

使用“模板”里的学生、考场、教师、考试四类 Excel 模板，也可在程序中下载。
模板如有示例行，导入自己的资料前请删除示例行；学号和考号按文本填写，保留前导零。
学生、科目中的年级须与本次考试已经设置的年级一致；预检提示未知年级时，先核对表格，确需增加年级则回到基础资料修改年级设置。
导入时先查看预检结果，确认新增、更新、删除条数；有错误先修正资料再导入。
学生资料、考场布局和时间变更后，请按界面提示重新编排或复核相关结果。

四、保存与备份

已经确认的修改保存在本机；日程和设置中的待保存输入，需按界面提示点击保存。
方案菜单中的“另存方案”生成 JSON 备份。将这份文件复制到另一个安全位置；只保存导出的 Excel 或 PDF 不等于备份完整方案。
Mac 的程序包将考试资料放在“文稿/考场编排”；Windows 将考试资料放在解压后的程序文件夹。请不要删除这些资料目录。
升级、迁移电脑或删除程序前先另存并核对备份。跨电脑导入会建立新的方案副本；激活码与电脑关联。

五、导出与打印

先处理“检查与确认”中的必须处理项，再导出正式材料；有硬性问题时可以导出标明“草稿”的材料供核对。
Excel、PDF 等材料生成后，可打开文件或所在文件夹。打印前核对纸张、方向、页数、考场和学生名单。
PDF 生成使用本机 Chrome 或 Edge；缺少可用浏览器时程序会生成可打印 HTML。用浏览器打开 HTML 后可以打印或另存 PDF。
选择 A3 版式时，打印机或打印服务也需支持 A3。正式批量打印前先核对一页。

六、试用与激活

程序提供三天试用；试用结束仍能查看、编排和保存，导出与打印需要激活。
左下角“外观与设置 → 激活与机器码”可查看本机机器码并输入激活码。请向软件提供者获取本机激活码。
考试资料与求解留在本机；资料不会上传到构建仓库。检查软件更新会连接本项目的 GitHub 发布页面。

完整操作说明见随包“使用手册.md”，程序左下角也提供“使用说明”。

Windows 实机测试清单由总协调随本次交付提供。交付后停止追加开发和测试，等待你的实机反馈。
